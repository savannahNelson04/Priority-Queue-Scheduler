Task Scheduler with Priority Queue <br>

This project implements a task scheduling system using priority queues (min-heaps) to optimize job execution order. It applies the Shortest Processing Time First (SPT) algorithm to minimize average completion time and simulates real-world cloud scheduling scenarios. <br>

#Features <br>
-Shortest processing time first (spt) scheduling<br>
-Uses a priority queue (min-heap) to efficiently select jobs<br>
-Handles priority-based job scheduling<br>
-Simulate dynamic task arrival<br>
-Calculates average completion time <br>
